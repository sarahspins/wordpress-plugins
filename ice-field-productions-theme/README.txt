4. Appearance > Menus: create and assign the Primary Menu.

HEADER AND FOOTER EDITING
The header and footer are no longer hardcoded.

Header:
- Appearance > Customize > Header Options:
  - Edit the header button text and URL
  - Show or hide the button by clearing its URL
  - Change the header background
  - Enable or disable the sticky header
- Appearance > Customize > Site Identity:
  - Add or replace the logo
  - Change the website title and tagline
- Appearance > Menus:
  - Edit and reorder the Primary Menu
- Appearance > Widgets:
  - Add optional content to Header Utility Area

Footer:
- Appearance > Customize > Footer Options:
  - Edit the introductory heading and text
  - Change footer and heading colors
  - Edit copyright/organization wording
- Appearance > Menus:
  - Assign menus to Footer: The Show, Participants, Audience, Support, and Legal / Bottom
- Appearance > Widgets:
  - Footer Introduction and Footer Columns 1–4 can accept Navigation Menu, Paragraph, Image, Social Icons, or other blocks
  - Footer Bottom can replace the default copyright/legal row

The default header and footer content remains visible until you replace it.

Appearance > Customize > Header Options now includes:

VERSION 1.3.0 — FULLY EDITABLE HOMEPAGE

The homepage is now a normal WordPress page edited with Gutenberg.

SETUP
1. Go to Pages > Add New and create a page named Home.
2. Go to Settings > Reading.
3. Select “A static page” and choose Home as the Homepage.
4. Edit the Home page.
5. Click the blue + button, choose Patterns, and open the Ice & Field Productions category.
6. Insert any of these starter patterns:
   - Show Hero
   - Join Watch Support Cards
   - Production Story
   - Participant Hub
7. Click any text, image, button, or link to edit it.
8. Drag blocks in List View to rearrange sections.
9. Use any standard WordPress blocks for video, galleries, columns, sponsor logos, FAQs, or additional content.

The homepage no longer relies on hardcoded text in front-page.php.
The Customizer homepage fields from earlier versions remain available for compatibility, but Gutenberg page content takes priority.

TIP
Use List View in the top-left of the block editor to select, move, duplicate, or delete complete homepage sections.
